# Reference Documents

Local reference copies may be placed in this directory for development convenience. The reference documents themselves are intentionally ignored by git.

Suggested local filenames:

- `rfc5280.txt` - RFC 5280, Internet X.509 Public Key Infrastructure Certificate and CRL Profile.
- `rfc8032.txt` - RFC 8032, Edwards-Curve Digital Signature Algorithm, including Ed25519.
- `rfc8446.txt` - RFC 8446, The Transport Layer Security Protocol Version 1.3.
- `rfc6762.txt` - RFC 6762, Multicast DNS.
- `rfc6763.txt` - RFC 6763, DNS-Based Service Discovery.
- `json-rpc-2.0.md` - JSON-RPC 2.0 Specification.
- `kde-connect-protocol.md` - KDE Connect protocol documentation.
- `kde-connect-cve-2025-66270.patch` - KDE Connect fix commit for CVE-2025-66270.
- `kde-connect-cve-2025-32900.patch` - KDE Connect fix commit for CVE-2025-32900.
- `kde-connect-cve-2025-32898.patch` - KDE Connect fix commit for CVE-2025-32898.
